  For this project, I worked on the pirate intelligent agent in a Jupyter Notebook. I was given starter code that set up the game world and some basic functions. My main job was to write the Q‑learning parts myself, like updating the Q‑values and training the pirate so it could figure out how to reach the treasure. I also cleaned up the notebook and made sure everything ran correctly.
  This project helped me understand what computer scientists actually do. We take a problem, break it down, and figure out how to teach a computer to solve it. Reinforcement learning is a good example because you have to think about states, rewards, and how the agent should react.

  I also learned that computer scientists have ethical responsibilities. Whatever we build affects real people, so we need to make sure our code is safe, fair, and reliable. Even small projects help build that mindset.

  This course helped me understand reinforcement learning in a hands‑on way. I learned how to train an agent, debug issues, and think more like a computer scientist. Adding this project to my portfolio gives me something real to show employers, and it makes me feel more confident moving forward in the field.
